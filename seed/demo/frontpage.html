Hello, world.

This is a real, vanilla install of MindAttic.Ideas — a CMS where a page, a theme or a widget goes live the moment you upload it, with no redeploy and no restart. Every first-party .idea package is already installed. This page is the only content.

This demo wipes itself every hour and comes back with a brand-new admin password. Nothing you do here is kept, so break anything you like.

Sign in

The current admin login is on the MindAttic Ideas page — click Show demo login. Then go to /admin.

Things to try

  • Make a page. Admin → Page Management → New. Write free-form HTML and drop components in as tags, e.g. <Component.Card title="Hi" /> or <Component.Accordion />.
  • Change the look. Pick another theme for a page — Autumn, Spring, Summer, Winter, Cyberspace, Hardware — and flip light/dark with the toggle at the top of the page.
  • Turn on plugins. Header, breadcrumbs, footer, back-to-top: each is one checkbox on a page.
  • Upload a package. Admin → Upload Idea takes a signed .idea and it is live at once.
  • Tune an instance. Every component and theme on a page has its own settings — colors, spacing, typography — without touching code.
